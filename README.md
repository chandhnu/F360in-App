# F360in - Personal Wealth Operating System

A premium Flutter application for managing personal, family, HUF, and business finances.

## Quick Start

```bash
cd f360in_app
flutter pub get
flutter run -d web
```

## Project Structure

- `lib/` - Dart source code (Clean Architecture)
- `lib/domain/` - Business logic & models
- `lib/data/` - SQLite database & persistence
- `lib/presentation/` - Flutter UI
- `pubspec.yaml` - Dependencies
- `analysis_options.yaml` - Linter rules

## Features

- Premium dark theme dashboard
- Asset allocation visualization
- Cash flow analysis
- Financial goals tracking
- Investment holdings with XIRR
- Profile switching (Individual/Family/HUF/Business)
- Clean Architecture with Riverpod

## Technology Stack

- Flutter 3.0+
- Riverpod (state management)
- GoRouter (navigation)
- SQLite (database)
- Material 3
